# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text will be copied here before the project opens to contributors.

In short: be respectful, assume good faith, accept constructive criticism, and focus on what is best for the community.
Harassment or discrimination of any kind is not tolerated.

Report concerns to the maintainer using the contact in the repository profile (a dedicated address will be added
before contributions open). Reports are handled in confidence.
